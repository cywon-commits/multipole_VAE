# 의뢰서: S² 유효장 VAE의 결합 디코더 — 2차원 검증

저장소: `github.com/cywon-commits/S2_VAE_for_spin_structures`
요청자: Changyeon Won (경희대 물리학과)
작업 위치: 저장소에 `twod/` 디렉터리로 이 패키지를 넣고 그 안에서 작업. 결과는 `twod/results/`, 보고서는 `twod/REPORT.md`.

## 0. 배경 (한 문단)

디코더가 스핀이 아니라 유효장 h를 출력하고 관측 모형을 vMF(볼츠만) 분포로 두는 VAE를, 격자점 간 결합(교환·DMI·비등방 교환)을 포함하도록 확장했다. 결합이 있어도 각 격자점의 조건부 분포는 분자장 hᵉᶠᶠ를 갖는 vMF이므로, 분배함수 없이 두 추정량으로 학습할 수 있다.

- **의사우도(PL):** 닫힌 형태이며 해밀토니안 매개변수에 대해 볼록하다.
- **구면 score matching(SM):** 손실이 ½|S×g|²(토크 제곱) − ΔW이고 매개변수에 대해 이차형식이므로, 선형 풀이 θ* = M⁻¹b 한 번으로 끝난다. Q(단일점 l=2)도 다룰 수 있다.

1차원 사슬에서는 다음을 확인했다.

- Fisher 정확해를 재현했다.
- J와 D를 편향 없이 복원했고, 없는 성분은 0으로 나왔다.
- DMI 피치 항등식 ⟨ê·(Sᵢ×Sᵢ₊₁)⟩/⟨S⊥·S⊥⟩ = D/J를 확인했다.
- 상관함수가 격자 가우시안 해와 일치했다.
- 독립 디코더의 κ 과대평가 κ_ind = √(κ(κ+4J))가 정량적으로 맞았다.
- 공선 질서에서는 (J, κ, Γ_zz)에 조화 차수 평탄 방향 (1, −6, −1)이 있어 Γ가 식별되지 않는다는 것을 발견했다.

이번 작업은 이를 2차원으로 옮기고(Stage 1), 이어서 VAE 자체를 시험한다(Stage 2).

## 1. 설계 원칙 (변경 시 먼저 보고)

1. **대칭 → 해석 → 작은 계산 → 큰 계산 순서.** 수치가 해석 예측과 어긋나면 크기를 키우지 말고 원인부터 보고한다.
2. **SO(3)ₛ 등변성.** 잠재변수를 회전하면 디코더 출력(h는 l=1, J⁽⁰⁾는 l=0, D는 l=1, Γ와 Q는 l=2)이 그 표현대로 회전해야 한다. DMI와 외부장처럼 대칭을 깨는 고정 텐서는 함께 회전하는 외부 입력(spurion)으로 취급한다.
3. **디코더는 일반적으로 둔다.** 특정 다극을 겨냥하지 않고 l ≤ 2를 열어 두며, 어느 성분이 쓰이는지는 학습 결과로 판단한다. 대칭 분석은 예측으로만 사용한다.
4. **결합은 처음에 전역(z 무관)·최근접으로 제한한다.** 사후분포 붕괴를 막기 위해서다. z 의존 결합은 Stage 2 후반에 시도한다.
5. **공선 데이터에서는 Γ와 Q를 묶어 0으로 두거나, 열어 둘 경우 평탄 방향을 보고한다.** 비공선(스커미온) 데이터에서는 모두 연다.
6. **목표 수치에 맞추려고 데이터나 매개변수를 조정하지 않는다.** 실패는 그대로 보고한다.

## 2. 패키지 사용

`README.md` 참조. 먼저 `python -m pytest -q tests/`를 실행한다(8개 통과, torch 테스트 1개는 건너뜀). 모든 스크립트는 `--quick`로 수 분 안에 끝나는 축소판을 돌릴 수 있다. 이 패키지 작성 시 `--quick`과 축소 경로는 모두 실행해 확인했고, 전체 크기 실행은 하지 않았다.

규약은 다음과 같다(`s2spin/model.py`).

- **로그 가중치:** W = Σ h·S + ŜᵀQŜ + Σ_μ Sᵣᵀ J_μ Sᵣ₊μ이고, 역온도는 흡수한다. 양의 J는 강자성이다.
- **interfacial(Néel) DMI:** D_x = D ŷ, D_y = −D x̂.
- **bulk(Bloch) DMI:** D_μ = D μ̂.
- **매개변수 순서:** `estimators.NAMES`의 26개. 방향별로 J0, D(3), G(5)를 두고, 그 뒤에 h(3), Q(5)가 온다. G는 정규직교 기저(GAMMA_BASIS) 성분이며, Γ = γ diag(1,1,−2)이면 G2 = √6 γ이다.

## 3. Stage 1 — 2차원 추정량 시험 (VAE 없음)

### 1a. 가우시안 영역 (`scripts/stage1a_gaussian.py`)

**설정:** 등방 J ∈ {2, 5, 20}, κ = 10 (ẑ), L = 32.

**합격 기준:**
- 횡상관 C(r)가 격자 가우시안 2G(r)와 r ≤ 2에서 5% 안으로 일치한다(⟨|δ|²⟩ < 0.1인 경우). 차이의 부호는 비조화 보정 방향(MC가 작음)이어야 한다.
- κ_ind(J를 무시한 vMF 최대우도)가 1/G(0)와 3% 안으로 일치한다.
- x/y를 묶은 (J, h_z)의 SM·PL 추정이 참값과 3σ(잭나이프) 안에 든다.
- 21개를 모두 열면 cond(M)가 10³ 이상으로 커지고, 평탄 방향 비율이 dκ/(dJx+dJy) ≈ −6, G2_μ/(−√6 dJ_μ) ≈ 1로 나온다(dJ_μ가 오차보다 클 때만 의미 있음).
- ⟨|δ|²⟩가 κ 감소에 따라 Mermin–Wagner 로그 경향을 따른다. lattice 2G(0) 예측과 비교하고, 작은 κ에서 가우시안 근사가 벗어나는 지점을 보고한다.

### 1b. DMI 복원 (`scripts/stage1b_dmi.py`)

**설정:** J = 1, B = 0.4 ẑ. 경우는 (없음), (interfacial D = 0.3, 0.6), (bulk D = 0.3, 0.6)이고, β ∈ {0.5, 1, 2}, L = 32.

**합격 기준:**
- 0이 아닌 모든 매개변수가 3σ 안에 든다.
- 0인 매개변수는 21개 중 최대 |z| < 3.5다.
- SM과 PL의 차이가 오차 수준이다.
- Moriya 방향 오차가 2σ 각도 안에 든다. 축소판에서는 1–2°였다.
- θ/β가 β에 무관하다(3σ).

### 1c. 스커미온 격자 (`scripts/stage1c_skx.py`)

**설정:** J = D = 1 interfacial, β = 6, B ∈ {0.2, 0.4, 0.6, 1.5}, L = 48. 어닐링으로 준비한다.

**합격 기준:**
- B = 0.4–0.6에서 ⟨Q⟩ ≠ 0, B = 1.5에서 Q = 0(편극 상태)이다.
- 26개 매개변수(Γ, Q 포함)가 비공선 SkX에서는 cond(M) ≲ 10²로 식별되고, 모두 3σ 안이며, 0인 성분은 최대 |z| < 3.5다.
- B = 1.5(공선)에서는 cond(M) ~ 10⁴로 다시 퇴화한다. 이 대비가 핵심 결과다.

축소판(L = 24)에서 관찰한 값은 다음과 같다. B = 0.4: ⟨Q⟩ ≈ −8.4, cond ≈ 92. B = 1.5: Q = 0, cond ≈ 1.6×10⁴.

### Stage 1 공통 보고

각 경우마다 다음을 보고한다.
- 자기상관 시간(τ_int)과 표본 간격
- 매개변수 표
- 잭나이프 오차(체인 단위 그룹)
- cond(M)
- 그림: 1a의 C(r) 비교, MW 경향, 1c의 스핀 텍스처 예시와 Q 분포

## 4. Stage 2 — VAE 시험 (Stage 1 통과 후)

### 데이터

`scripts/stage2_make_ensembles.py`로 만든다.

- **E1 (장 방향 앙상블):** 등방 J = 5, κ = 10. 장 방향 n이 표본마다 무작위다. ẑ 표본에 무작위 R ∈ SO(3)ₛ를 적용해 정확히 생성한다. 레이블은 n이다.
- **E2 (SkX):** 무작위 격자 이동과 결합 C4(공간 90° + 스핀 z축 90°, 대칭임을 스크립트가 수치로 확인)를 적용한다. 레이블은 이동량, C4 지표, Q다.

### 모델

- **인코더:** SO(3)ₛ 등변(e3nn 또는 vector-neuron류)이고 병진 등변(합성곱)이다. 잠재변수는 l = 0, 1 채널을 갖는다.
- **디코더:**
  - (a) 독립 디코더: 국소장 h만 출력한다(vMF).
  - (b) 결합 디코더: 국소장 h에 전역 결합(묶인 등방 J; E2에서는 J, D를 spurion으로)을 더한다.
- **손실:** 의사 ELBO = 의사우도 재구성 + β·KL. 비교용으로 결합 매개변수만 SM으로 학습하는 교대 방식을 둔다.
- **구현:** `s2spin/torch_losses.py`를 쓰되, 먼저 `tests/test_torch_losses.py`를 통과시킨다. 이 파일은 작성 환경에 torch가 없어 실행되지 않았다.

### 시험과 예측

1. **E1 독립 디코더:** 학습된 국소 κ가 1/G(0) ≈ 26에 가깝게 과대평가되고(참값 10), 조건부 상관은 0이다.
2. **E1 결합 디코더:** 전역 J ≈ 5, 국소 κ ≈ 10이 복원되고, z가 생성한 해밀토니안에서 열욕 MC로 생성한 표본의 C(r)가 2G(r)와 일치한다.
3. **등변성:** 입력을 무작위 R로 회전하면 l = 1 잠재변수와 출력장이 같은 R로 회전한다(상대 오차 < 10⁻⁵).
4. **잠재변수 진단:** E1에서 잠재 l = 1 성분과 n의 정렬도를 보고, E2에서 잠재변수가 이동·C4를 담는지 본다. 차원별 KL을 감시하고, 붕괴 징후가 보이면 β와 free bits로 대응한 내용을 기록한다.
5. **(선택) E2에서 l = 2 국소 출력:** 텍스처 위상 불확실 영역에서 띠(girdle) 형태의 Q가 나타나는지 본다. 예측일 뿐 목표가 아니다.

## 7. 열린 질문 (결과와 함께 의견 보고)

- 결합 디코더에서 J를 z 의존으로 풀었을 때 잠재 정보가 J로 새는 정도(사후분포 붕괴)는 얼마인가.
- E2에서 l = 2 국소 출력이 실제로 필요한 영역이 있는가.
- 3체 키랄 항(K·χ)을 국소 위상전하 제약으로 넣을 가치가 있는가.
