## 0. Stage 2b 검토 결과

Stage 2b의 보고와 판단은 승인한다. 관련 정정은 다음과 같다.

| 항목 | 판단 |
|---|---|
| E3 결합 디코더가 B를 담음 | 핵심 가설 확인 |
| E3 SM 교대 s1이 l=1 채널 사용 | 의뢰서의 대칭 예측 오류. ẑ spurion이 입력되면 잔여 대칭군(ẑ축 회전)의 스칼라 부분공간은 l=0과 l=1의 ẑ 성분을 함께 포함한다. 기준을 "B는 잔여 대칭군의 스칼라 부분공간에 담긴다"로 정정한다 |
| E3 평균 z의 R²가 R²_max를 넘음 | 모순이 아니다. 사후분포 잡음은 디코더가 필요한 정밀도로, 사후 평균의 정확도는 인코더가 가진 정보로 정해진다. R²_max는 표본 z에 대한 예측이다 |
| E3 독립 디코더 | 전역 잠재변수 구조로는 텍스처를 표현할 수 없다. 구조를 반영하지 못한 의뢰서의 예측 오류다 |
| 마스크 시험 | 의뢰서 오류 두 가지: (1) "ℓ=1 사이트는 이웃 4개를 다 본다"는 25% 무작위 마스크에서 틀렸다. (2) 인코더가 마스크 위치를 모르면 텍스처 비용은 전 영역에 대해 내고 이득은 마스크 영역에서만 얻는다는 점을 빠뜨렸다. J, D 편향은 모형 오설정(§3.1)으로 본다 |
| E1의 +1.5% 편향 | 장 방향 잡음 이론(§1)으로 매개변수 없이 설명된다. 이번 단계에서 검증한다 |

이번 단계의 공통 주제는 "β = 1의 VAE가 각 정보를 얼마의 정밀도로 보내는가는 디코더 Fisher 정보와 KL 비용의 균형으로 정해진다"이다. 세 작업 모두 이 원리의 정량적 예측을 시험한다.

## 1. 작업 A — E1 편향: 장 방향 잡음 이론 (가벼움, 최우선)

### 1.1 이론 (채팅에서 유도하고 합성 데이터로 검증함)

디코딩된 장이 참 방향에서 가로로 ε만큼 어긋나면, 가우시안 차수 PL에서 국소장의 몫 κ/P가 줄고 그 몫을 결합 J가 대신 맡는다. 기호는 P = κ + 4J, a = J/P, r = κ₀/P₀이다.

```
dJ/J  = [4r/(a0 Σ2) − P0 r²] · s²_eff
dκ/κ  = −[P0 r² + 16/Σ2]      · s²_eff
Σ2    = (1/N) Σ_q γ_q² S(q),   γ_q = 2cos qx + 2cos qy,   S(q) = 1/(κ0 + J0(4 − γ_q))
```

L = 32, J = 5, κ = 10에서 Σ2 = 0.1825이므로 dJ/J = +40.5 s², dκ/κ = −91.0 s²이고 비율은 −2.25다(정확한 vMF에서 −2.17).

**유효 잡음.** 사후 평균의 오차가 데이터의 q=0 모드(총자화 방향)에 회귀계수 c로 묶여 있으면 다음과 같다.

```
s²_eff = s²_noise + resid + (c² − 2c)/(N κ0)
```

c = 1이면 −1/(Nκ₀) ≈ −1.0×10⁻⁴로, 반대 부호의 보정이다. M̂로 정규화하면 c ≈ 1/⟨cosθ⟩ ≈ 1.04가 된다.

**잡음의 크기는 VAE의 rate–distortion 균형으로 정해진다.** l=1 등방 가우시안 잠재변수(스칼라 로그분산)로 방향을 보낼 때의 관계는 다음과 같다.

```
KL ≈ −(3/2) ln(3 s²)
```

재구성 비용은 표본당 N κ_eff s²이다. 결합 디코더에서 κ_eff = κ₀²/P₀ = 3.33(측정 3.29–3.53), 독립 디코더에서 κ_eff = κ_ind ≈ 25.7(측정 24.8–26.6)이다. 두 비용을 맞추면 다음을 얻는다.

```
s²* = 3β / (2 N κ_eff),    KL* = (3/2) ln(2 N κ_eff / (9β))
```

이미 관측된 값과의 대조는 다음과 같다(시드 3개).

| | 예측 | 관측 |
|---|---|---|
| KL, 결합 | 9.95 nat | 9.6–10.1 |
| KL, 독립 | 13.01 nat | 12.9–13.1 |
| KL 차이 | (3/2) ln(κ_ind P₀/κ₀²) = 3.06 | 3.0 |
| dJ/J (c=1 / c=0) | +1.38% / +1.78% | +1.49%, +1.53% |
| dκ/κ (c=1 / c=0) | −3.11% / −4.00% | −3.8%, −3.1% |

합성 검증(`scripts/stage2c_e1_bias.py --synthetic`)에서는 독립 잡음 s² = 10⁻⁴, 3×10⁻⁴, M̂ 방향(c=1)에 대해 dJ/J와 dκ/κ가 예측과 3–7% 상대오차 안에서 일치했다. 차이는 비조화 보정이다.

### 1.2 할 일

1. **VAE 덤프 분석.** E1의 결합 PL 모델(시드 3개 중 하나 이상)에서 검증 표본마다 다음을 저장하고 `python stage2c_e1_bias.py --vae dump.npz`를 실행한다.
   - 참 장 방향이 ẑ가 되도록 되돌린 스핀(Rᵀ 적용)
   - 표본 z에서 디코딩한 장 방향
   - 사후 평균에서 디코딩한 장 방향
   - 학습된 J, κ와 사용 채널의 KL

   덤프 형식은 스크립트 머리말에 있다. 출력되는 값은 측정 s², 회귀계수 c, 두 방향으로 다시 맞춘 J와 κ다.
2. **크기 축척.** L = 64에서 결합 PL을 시드 2개로 돌린다(같은 κ, J, β = 1). 예측은 KL* = 12.03, dJ/J = +0.35%, dκ/κ = −0.78%다.
3. **β 축척.** L = 32, β ∈ {0.25, 0.5, 1}에서 결합 PL을 시드 2개씩 돌린다. 편향은 β에 대해 직선이어야 한다.
   ```
   dJ/J(β) = cJ · [3β/(2Nκ_eff) − c/(Nκ0)]
   ```
   절편으로 c를 독립적으로 얻을 수 있다. 예측(c = 1)은 β = 0.25에서 +0.05%, 0.5에서 +0.49%, 1에서 +1.38%다. KL은 β가 1/4이 될 때마다 (3/2)ln 4 = 2.08 nat씩 증가한다. 스크립트 `--predict --beta`로 각 값을 출력할 수 있다.

### 1.3 합격 기준

| 항목 | 기준 |
|---|---|
| 측정 s² | s²*의 ±30% |
| c | 0.8–1.2 (M̂ 정규화 기준 ≈ 1.04) |
| 표본 방향 재적합 | 같은 데이터에서 VAE의 dJ/J, dκ/κ를 각각 0.3%p 안으로 재현 |
| 평균 방향 재적합 | dJ/J가 −0.4% ± 0.2%p (c 항만 남음) |
| L = 64 | 편향이 L = 32의 1/4 ± 50%, KL이 12.0 ± 0.4 |
| β 축척 | 편향이 β에 대해 직선, 절편에서 얻은 c가 1번의 c와 0.2 안 |

## 2. 작업 B — E3 재판정 (재학습 없음)

### 2.1 이론

정정된 대칭 기준은 다음과 같다. 장 세기 B는 잔여 대칭군의 스칼라 부분공간에 담긴다. 그 부분공간은 l=0 채널과, ẑ spurion이 입력된 경우 l=1 채널의 ẑ 성분이다.

**스칼라 가우시안 채널의 정보 항등식.** 사후 평균이 B의 단조 함수이고 잡음이 가우시안이면, 표본 z의 R²와 상호정보량 사이에 다음이 성립한다.

```
I(B; z) = −½ ln(1 − R²_sample),    KL_used ≥ I
```

관측값과의 대조: R² = 0.906, 0.891, 0.909이면 I = 1.18, 1.11, 1.20이고, 관측 KL은 1.32, 1.26, 1.34다. 차이 0.1–0.15 nat는 집계 사후분포와 사전분포의 불일치로 본다. l=1 실행은 R² = 0.822에서 I = 0.86이고 KL은 1.54다. 차이 0.68 nat는 쓰이지 않는 가로 두 성분의 낭비로 본다.

**최적 잡음.** 디코더의 B Fisher 정보를 I_dec, t = (B 단위 잡음 분산)/Var(B)라 하자. KL과 재구성 비용(½ I_dec Var(B) t)을 균형시키면 다음과 같다.

```
l=0:  KL(t) = ½ ln(1 + 1/t),           최적  t(1 + t)   = 1/(I_dec Var B)
l=1:  KL(t) = (3/2) ln(1 + 1/(3t)),    최적  t² + t/3   = 1/(I_dec Var B)
R²_sample = 1/(1 + t)
```

I_dec = I_PL로 두면 1/(I_PL Var B) = σ_B²/Var B = 0.058이다. 이때 예측은 l=0에서 R² = 0.948, l=1에서 0.888인데, 관측은 0.89–0.91과 0.822다. 반면 I_dec = I_PL/2라는 하나의 가정을 두면 두 경우가 함께 맞는다. 이 경우의 예측은 l=0에서 R² = 0.905, KL = 1.18이고, l=1에서 R² = 0.825, KL = 1.42다. 관측 KL은 각각 1.26–1.34, 1.54로 두 경우 모두 약 0.1 nat 높다. 따라서 디코더가 실제로 쓰는 Fisher 정보가 PL 상한의 절반이라는 가설이 남는다.

### 2.2 할 일

1. **잔여 대칭 부분공간.** 네 결합 실행 각각에서 사용된 채널의 사후 평균이 그 부분공간(l=0, 또는 l=1의 ẑ 성분) 안에 있는지 확인한다. 측정할 것은 l=1 채널 분산의 ẑ 성분 비율, 그리고 l=1 실행의 가로 성분 사후분산과 그로부터 계산한 낭비 KL Σ½(σ² − 1 − ln σ²)다. 이 값을 0.68 nat와 비교한다.
2. **정보 항등식.** 실행별로 −½ ln(1 − R²_sample)과 KL_used를 표로 정리한다.
3. **I_dec 측정.** 검증 표본에서 디코더 출력의 B 의존 부분을 δB만큼 이동했을 때 재구성 손실의 곡률을 잰다. 예를 들어 z의 해당 성분을 B 단위로 바꿔 이동시킨다. 측정한 I_dec/I_PL과 그 값으로 다시 계산한 최적 t, R², KL을 관측값과 비교한다.

### 2.3 합격 기준

- 네 실행 모두 잔여 대칭 부분공간을 쓴다.
- 모든 실행에서 KL_used ≥ −½ ln(1 − R²_sample)이다.
- 측정한 I_dec로 계산한 R² 예측이 관측과 0.03 안이다.
- I_dec/I_PL이 1이 아니면, 그 이유에 대한 가설과 검증 방법을 보고한다. 이 부분은 판정이 아니라 보고 대상이다.

## 3. 작업 C — 마스크 시험 재설계 (본 작업)

### 3.1 J, D 편향의 원인 가설

관측 이웃이 일부만 남은 마스크 사이트에서는, 빠진 이웃의 몫을 남은 이웃이 대신해야 같은 집중도가 나온다. 공유된 J가 이 때문에 위로 끌려간다는 가설이다. 이 가설이 맞다면 편향은 관측 이웃이 1–3개인 마스크 사이트의 비율 f_partial(ℓ)을 따라가야 한다. 대략적인 비교로 ℓ = 2 (≈1.0), 4 (0.75), 1 (0.68), 8 (0.44)이고, Stage 2b의 J 편향은 +9.6, +9.3, +6.4, +7.1%였다.

### 3.2 판정 부등식

마스크 사이트 하나당 텍스처를 알 때의 이득을 Δ, 텍스처를 보내는 사이트당 비용을 r_tex라 한다. E2 독립 디코더(β = 0.01)에서 Δ ≈ (5155 − 3702)/2304 ≈ 0.63 nat이다.

- **마스크를 인코더도 알 때:** 비용과 이득이 모두 ρ에 비례하므로, 잠재변수 사용 여부는 Δ > r_tex로 정해지고 ρ와 무관하다.
- **마스크를 인코더가 모를 때:** 비용은 전 영역(N·r_tex), 이득은 ρNΔ이므로 ρ > ρ* = r_tex/Δ일 때만 쓴다.

### 3.3 설계

**디코더 변형.**
- **M1:** 마스크 사이트의 조건부는 이웃 결합 없이 h_z(i)만 쓴다. 마스크 사이트는 독립 vMF가 되고, J와 D는 비마스크 항에서만 학습된다.
- **M2:** 마스크 사이트에 별도 결합 J′, D′를 두고 관측 이웃만 쓴다.

**인코더.**
- **K(known):** 마스크를 l=0 입력 채널로 준다.
- **U(unknown):** 마스크를 주지 않는다(Stage 2b와 같음).

**학습.** β 예열(첫 20에폭 동안 0 → 1), 그 뒤 β = 1이다. 비교를 위해 대표 조합 하나는 예열 없이도 돌린다.

**스캔.**
- K + M1: ℓ ∈ {2, 4, 8, 16}, ρ ∈ {0.25, 0.5}
- U + M1: ℓ = 8, ρ ∈ {0.25, 0.5, 1.0}
- M2: ℓ ∈ {2, 8}, ρ = 0.25 (K)

시드는 각 2개다.

**대조군.** E2 독립 디코더(ρ = 1에 해당)를 β 예열과 함께 β = 1로 다시 돌린다. Stage 2에서는 붕괴했지만 이득(약 1450 nat)이 비용보다 훨씬 크므로, 붕괴는 최적화 문제였다는 것이 예측이다.

### 3.4 예측과 합격 기준

| 항목 | 예측 / 기준 |
|---|---|
| M1, M2의 J, D | 0.5% 안 (편향 소멸 = §3.1 가설 확인) |
| 기존 공유 J 편향 대 f_partial(ℓ) | 마스크 생성기로 f_partial를 정확히 계산해 상관을 보고 (판정 아님) |
| K + M1의 잠재변수 사용 | 모든 ℓ에서 KL > 1 nat. 같은 ℓ에서 KL/ρ가 ρ = 0.25와 0.5 사이에 ±25% 안 |
| K + M1의 마스크 영역 | R(k) > 0.9. 마스크 사이트 손실이 z 없을 때보다 사이트당 ≥ 0.4 nat 감소 |
| r_tex | K + M1에서 KL/(ρN)로 측정하고 ℓ별로 보고 |
| U + M1 | ρ > ρ* = r_tex/Δ에서만 KL > 1 nat. ρ*는 K 실행에서 측정한 r_tex와 Δ로 사전 계산해 보고서에 먼저 적고 나서 판정 |
| 대조군(E2 독립, 예열) | KL ≫ 1, R(k) > 0.9 |
| 예열 없는 대표 조합 | 결과를 그대로 보고 (붕괴하면 최적화 문제의 증거) |

## 4. 공통 규칙

- 결과를 맞추려고 조정하지 않는다. 사후 조정은 처음 결과와 함께 적는다.
- 시드 수를 모든 표에 적는다.
- 예측이 틀리면 원인 가설과 구별 실험을 제안하되, 실험은 다음 의뢰를 기다린다.
- 코드 규약(부호, 매개변수 순서, DMI 방향)을 바꾸면 명시한다.
- 우선순위는 A → B → C다. A와 B는 가벼우므로 C 전에 먼저 보고해도 된다.

## 5. 제공 파일

`scripts/stage2c_e1_bias.py`는 세 가지 모드로 쓴다.

- `--predict`: 해석 예측을 출력한다(L, J, κ, β 지정 가능).
- `--synthetic`: MC로 공식을 검증한다. 작성 환경에서 실행해 위 수치를 확인했다.
- `--vae dump.npz`: VAE 덤프를 분석한다. 작성 환경에서 합성 덤프로 실행해 확인했다(측정 s² 4.2×10⁻⁴, c = 1.04, 재적합 결과가 공식과 일치).
