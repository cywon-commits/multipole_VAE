## 0. Stage 2c 검토 결과

Stage 2c의 보고와 판정은 승인한다. 이번 단계에 영향을 주는 정정과 채팅에서 미리 계산한 결과는 다음과 같다.

### 0.1 E3: 의뢰서 공식 오류의 정정 (Stage 2c §2)

Stage 2c의 최적 잡음 공식은 왜곡을 선형 디코더 기준(½ I V t)으로 두었다. 학습된 디코더는 사후 평균에 가까운 베이즈 디코더이므로 왜곡은 사후분산 ½ I V (1 − R²)이다. 가우시안 원천에서의 해는 pPCA와 같다.

```
l=0:  R² = 1 − β/SNR,   KL = ½ ln(SNR/β)     (SNR < β이면 붕괴),   SNR = I_dec · Var(B)
```

따라서 I_dec = I_PL/2라는 가정은 철회한다. 측정값 I_dec ≈ I_PL과 모순이 없다.

균일 원천 1차원 장난감 VAE(`scripts/stage2d_toy_vae.py`)로 계산했다. 인코더 μ(B), σ(B)는 자유 함수이고 디코더는 베이즈 최적이다. SNR = 17.07(측정 I_dec/I_PL = 0.985 반영), β = 1에서의 값은 다음과 같다.

| | R² (표본 z) | R² (평균 z) | KL | 참 MI | −½ln(1−R²) |
|---|---|---|---|---|---|
| 균일, l=0 | 0.918 | 0.993 | 1.37 | 1.36 | 1.25 |
| 균일, l=1 | 0.854 | 0.999 | 1.66 | 0.96 | 0.96 |
| 관측, l=0 (3개) | 0.89–0.91 | ≈0.99 | 1.26–1.34 | — | 1.11–1.20 |
| 관측, l=1 (1개) | 0.822 | — | 1.54 | — | 0.86 |

- **균일 원천에서 최적 인코더는 비선형이다**(σ_max/σ_min ≈ 2.3). 그래서 평균 z의 R²가 0.99이고, 표본 z의 R² 차이가 0.04에서 약 0.015로 줄어든다.
- **보고서의 "KL − I = 0.14"는 대부분 인공물이다.** −½ln(1−R²)가 균일 원천의 MI를 과소평가해서 생긴다. 참 MI는 KL과 0.01 차이다.
- **남은 차이.** 관측은 장난감 최적보다 KL이 0.03–0.11 nat 낮고 R²가 0.01–0.03 낮다. 장난감에서 SNR ≈ 13–14에 해당한다. 보고서의 가설 2(미수렴)를 시험한다(§3).

### 0.2 마스크 J, D 편향: 공유 장 절충 (채팅 계산, `scripts/stage2d_mask_field_fit.py`)

z가 붕괴하면 디코더 장은 사실상 고정된다. 이때 하나의 장에 두 요구가 걸린다.

- **비마스크 사이트(PL):** h = βB = 2.4 ẑ를 원한다.
- **마스크 사이트(M1, 독립 vMF):** L(h_m) = ⟨S_z⟩_M, 즉 h_m ≈ 1.48을 원한다.

VAE 없이 전역 매개변수 (J, D, h_z)만 맞춘 결과다(L = 24, 표본 144개, 정렬된 무작위 블록).

| ℓ, ρ | 공유 h: dJ/J, dD/D, h_z | 분리 h_m: dJ/J, dD/D, h_z, h_m |
|---|---|---|
| 4, 0.25 | +3.5%, −11.6%, 1.57 | −0.7%, −0.3%, 2.43, 1.49 |
| 4, 0.5 | +4.7%, −11.8%, 1.51 | +0.3%, +0.1%, 2.40, 1.48 |
| 8, 0.25 | +4.1%, −11.4%, 1.57 | 0.0%, −0.2%, 2.41, 1.48 |
| 8, 0.5 | +5.1%, −11.4%, 1.52 | +0.5%, +1.0%, 2.45, 1.48 |

해석은 다음과 같다.

1. **장을 공유하면 h_z가 마스크 사이트 쪽 최적값으로 끌려간다.** PL 쪽은 J를 올리고 D를 내려 약한 장을 보상한다. 이것은 E1과 같은 구조의 메커니즘이다.
2. **마스크 사이트에 별도의 장을 두면 편향이 사라진다.**
3. **Stage 2c M1의 관측 편향은 공유 극한보다 작고 ρ와 함께 커진다**(ρ = 0.25에서 J +0.85%, D −2.1%; ρ = 0.5에서 J +2.3%, D −6.1%). 이는 디코더 장이 영역별로 부분적으로만 분리되는 경우, 예를 들어 합성곱 수용영역이 마스크 경계 근처에서 두 요구를 섞는 경우(보고서 제안 3)와 맞는다.

### 0.3 붕괴 판정 기준의 정정

ρ* = r_tex/Δ = 1.13이라는 논거는 β = 0.01 최적점의 평균값끼리 비교한 것이다. 이것은 β = 1의 판정 기준이 아니다. 올바른 기준은 rate–distortion 곡선의 초기 기울기이며, 모드별로는 역 water-filling이 성립한다.

```
KL(β) = Σ_k ½ ln(SNR_k/β)₊ ,     β_c = max_k SNR_k ,     dKL/d ln β = −(활성 모드 수)/2
```

가장 가치 있는 모드는 SkX의 전역 병진 위상(2개)이다. 위상 이동에 대한 디코더 Fisher 정보는 대략 사이트당 O(1) × N ≈ 10³이고, 사전분산은 주기 약 8의 균일분포로 약 5다. 따라서 SNR ~ 10⁴(자릿수 추정)이다. 이 추정이 맞다면 β = 1의 붕괴는 최적해가 아니다. 이번 단계에서 판정한다(§2).

## 1. 작업 A — 마스크 장 절충 (최우선)

### A1. 재학습 없이: 디코더 장의 공간 구조 읽기

1. **구조 확인.** Stage 2c의 K+M1, U+M1, M2 실행에서 디코더가 마스크를 입력으로 받는지 명시한다. 디코더의 수용영역 반경 r_RF도 적는다.
2. **장 프로필.** 검증 표본에서 디코더 장 h_z(r)를 다음 영역별로 평균한다.
   - 마스크 사이트
   - 비마스크 사이트를 가장 가까운 마스크 사이트까지의 거리 d = 1, 2, …, ≥ r_RF로 나눈 각 구간

   그림으로 보이고, 기준선 βB = 2.4와 h_m* = L⁻¹(⟨S_z⟩_M)을 함께 표시한다. h_m*는 데이터에서 계산한다.
3. **편향 회귀.** 각 실행의 J, D 편향을 다음 두 양에 대해 회귀한다.
   - f_near(ℓ, ρ): 비마스크 사이트 중 d ≤ r_RF인 비율(마스크 생성기로 정확히 계산)
   - 비마스크 영역의 평균 장 결손 2.4 − ⟨h_z⟩_unmasked

**예측.**
- 디코더가 마스크를 받지 않으면 h_z는 공간적으로 균일하고 1.5–1.6이며, 편향은 §0.2의 공유 극한에 가깝다.
- 마스크를 받으면 비마스크 영역 먼 곳에서 h_z → 2.4, 경계 근처에서 하강, 마스크 사이트에서 ≈ 1.48이다.
- J, D 편향은 장 결손에 비례한다. 기울기 부호는 결손이 클수록 J↑, D↓이다.

### A2. 재학습: 마스크 사이트 장의 분리

다음 두 변형을 학습한다.

- **M1-hm:** 마스크 사이트는 z와 이웃 없이 별도의 학습 가능한 균일 장 h_m 하나로 조건부를 만든다. 비마스크 사이트는 디코더 장 h(z)와 결합으로 만든다.
- **M2-hm:** M2에 같은 분리를 적용한다(마스크 사이트는 h_m과 J′, D′).

스캔은 K 인코더, ℓ ∈ {2, 8}, ρ ∈ {0.25, 0.5}, 시드 2개다. 학습 조건은 β 예열 후 β = 1이다.

**예측과 기준.**
- J, D가 참값과 0.5% 안이거나, 체인 단위 잭나이프 오차 3σ 안이다(채팅의 전역 적합에서는 |dJ/J| ≤ 0.7%, |dD/D| ≤ 1.0%, 표본 144개).
- h_m = h_m*(데이터에서 계산) ± 3%이다.
- 비마스크 영역 h_z = 2.4 ± 2%이다.
- M2-hm에서는 Stage 2c의 D 잔여 편향(−0.5 ~ −1%)이 기준 안으로 들어온다.

## 2. 작업 B — 붕괴는 최적해인가: 이력 시험과 β 스캔

### B1. 이력 시험 (판정 실험)

대상은 E2 독립 디코더(격자 잠재변수, Stage 2와 같은 구조)이고 시드는 2개다.

1. β = 0.01에서 수렴한 해에서 출발한다. 기존 체크포인트가 있으면 쓰고, 없으면 다시 학습한다.
2. β를 0.01에서 1까지 기하급수적으로 60에폭에 걸쳐 올린다(에폭당 약 ×1.08).
3. β = 1에서 수렴할 때까지 유지한다. 종료 조건은 손실의 상대 변화가 10에폭 동안 0.1% 미만인 것이다.

**판정.** 최종 β = 1 목적함수(재구성 + KL)를 붕괴해(5155.2, KL = 0)와 비교한다.

- **목적함수가 더 낮고 KL > 0이면** 붕괴는 최적화 문제로 확정된다.
- **연속 해가 스스로 KL → 0으로 가고 목적함수가 5155.2 이상이면** 붕괴는 최적해다.

곡선 전체(β, KL, 재구성)를 기록한다.

같은 시험을 K+M1-hm(ℓ = 8, ρ = 0.5)에도 적용한다. 먼저 β = 0.01에서 학습하고, 이어서 위 절차를 따른다.

### B2. 고정 β 스캔

대상은 E2 독립 디코더, β ∈ {0.01, 0.03, 0.1, 0.3, 1, 3}, 시드 2개다. 각 β에서 두 가지로 학습한다.

- **처음부터:** 그 β까지 20에폭 예열한다.
- **이어서:** B1 경로의 해에서 그 β까지 올라간 뒤 수렴시킨다.

KL(β) 곡선 두 개를 한 그림에 그린다.

**예측.**
- 이어서 학습한 곡선은 ln β에 대해 감소하고, 기울기 −(활성 모드 수)/2로 활성 모드 수의 변화를 읽을 수 있다.
- 처음부터 학습한 곡선이 이어서 학습한 곡선보다 낮은 KL(특히 0)로 떨어지는 β 구간이 있으면 그 구간은 최적화 실패다.

### B3. 위상 모드의 SNR 측정

B1이나 B2에서 KL > 0인 수렴 모델 하나로 측정한다.

1. 검증 표본의 디코더 장(사후 평균에서)을 Fourier 보간으로 격자 간격 이하 δ만큼 x, y로 이동한다.
2. 재구성 손실의 곡률 I_shift를 유한차분으로 잰다.
3. SNR_phase = I_shift · Var(shift)를 계산한다. Var(shift) = p²/12이고, p는 데이터의 SkX 주기(texture_peaks로 측정)다.

**예측.** SNR_phase ≳ 10³이고, β_c(B2에서 이어서 학습한 곡선이 0으로 가는 β)와 같은 자릿수다.

## 3. 작업 C — E3 수렴 확인 (가벼움)

PL s0, s1과 SM 교대 s0, s1을 수렴 종료 조건으로 다시 학습한다. 조건은 손실과 KL의 상대 변화가 10에폭 동안 0.1% 미만이고, 최대 300에폭이다.

**예측(장난감, SNR = 17.07):**
- l=0: R²(표본 z) = 0.918, R²(평균 z) = 0.993, KL = 1.37
- l=1: R²(표본 z) = 0.854, KL = 1.66

**기준.** R²는 0.015 안, KL은 0.05 안이다.

**여전히 미달이면 보고할 것.**
- 장난감에서 관측 R², KL을 재현하는 실효 SNR(`--snr` 스캔)
- 디코더 출력의 B 의존성이 사후 평균 E[B|z]와 일치하는지(베이즈 최적성)
- 인코더 σ(B)가 B 끝쪽에서 커지는지(장난감 예측 σ_max/σ_min ≈ 2.3)

## 4. 공통 규칙

- 우선순위는 A → B1 → C → B2/B3이다. A1과 C는 가벼우므로 먼저 보고해도 된다.
- 결과를 맞추려고 조정하지 않는다. 사후 조정은 처음 결과와 함께 적는다.
- 모든 표에 시드 수를 적는다.
- 예측이 틀리면 원인 가설과 구별 실험을 제안하되, 실험은 다음 의뢰를 기다린다.
- 코드 규약(부호, 매개변수 순서, DMI 방향)을 바꾸면 명시한다.

## 5. 제공 파일

`scripts/`에 넣는다.

- **`stage2d_toy_vae.py`:** 1차원 장난감 VAE. 실행은 `--source uniform|gaussian --snr S [--l1] [--beta b]`이고 한 경우에 수 초 걸린다. 작성 환경에서 §0.1의 값을 재현했다.
- **`stage2d_mask_field_fit.py`:** 공유 장과 분리 장의 전역 적합. `--quick`은 L = 24, 전체는 L = 48이다. 작성 환경에서 `--quick`으로 §0.2의 값을 재현했다.
