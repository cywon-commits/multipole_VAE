## 0. Stage 2d 검토 결과

Stage 2d의 보고와 판정은 승인한다. 특히 다음 세 결론은 이후 단계의 전제로 둔다.

- **β = 1 붕괴는 최적화 문제다(B1).** 앞으로 잠재변수 사용을 시험할 때는 β = 0.01에서 출발해 β를 연속으로 올리는 절차를 표준으로 쓴다. 처음부터 학습할 때 생기는 붕괴의 원인 분리(보고서 제안 2)는 이번 단계에서 다루지 않는다.
- **마스크 사이트에 별도의 장을 두면 J, D 편향이 사라진다(A2).**
- **K+M1-hm을 K+M1로 바꿔 이력 시험을 한 판단은 옳다.** 의뢰서가 요구한 K+M1-hm 시험은 구조상 자명한 결과가 나오는 것이었다.

### 0.1 A1의 "평탄한 결손"에 대한 해석 (채팅 계산)

비마스크 PL은 (h_z, J, D)에 대해 부드러운 골짜기를 가진다. 장이 약해지면 J↑, D↓가 그 몫을 메워 손실이 거의 늘지 않는다. h_z를 결손 δ만큼 고정하고 (J, D)를 다시 맞춘 결과(`scripts/stage2e_valley.py --quick`, L = 24, 표본 144개)는 다음과 같다.

| 결손 δ | dJ/J (단위 결손당) | dD/D (단위 결손당) | 비용, J·D 적응 (nat/표본) | 비용, J·D 고정 |
|---|---|---|---|---|
| 0.1 | +4.58% | −13.39% | 0.019 | 0.046 |
| 0.2 | +4.62% | −13.36% | 0.078 | 0.183 |
| 0.4 | +4.69% | −13.31% | 0.31 | 0.73 |
| Stage 2d M1 회귀 (20개) | +5.1% (절편 +0.19%) | −13.9% (절편 −0.29%) | | |

해석은 다음과 같다. J, D는 전역 매개변수이므로 경계에서 생긴 작은 힘에도 골짜기를 따라 움직인다. 그러면 먼 곳의 최적 장도 골짜기 위의 대응점으로 함께 옮겨 간다. 따라서 결손은 원인이 아니라 J, D 편향과 같은 골짜기 좌표이고, 경계 근처 국소 현상이 아니라 전역 수준 이동으로 나타난다. 같은 이유로 f_near와의 상관은 약하다.

공유 장 실행을 합친 회귀에서 J 기울기가 13.3으로 커지는 것은 Stage 2b 공유 모형의 두 번째 메커니즘 때문이다. 관측 이웃이 일부만 남은 마스크 사이트가 J를 직접 올리는 오설정이 J에 더해진다.

### 0.2 활성 모드 약 355개의 해석

L = 48 SkX에는 스커미온이 약 34개 있으므로, 활성 모드는 스커미온당 약 10개다(위치 2 + 형상·호흡 + 장파장 요동). 이어서 학습한 KL(β)의 기울기는 β ∈ [0.01, 3]에서 거의 일정하다(약 −180 ~ −210 nat/ln β). 이것은 이 구간에서 꺼지는 모드가 거의 없다는 뜻이고, 대부분의 모드가 SNR > 3을 가진다.

모드 수를 세는 대신 더 직접적인 예측이 있다. 역 water-filling에서는 활성 잠재 차원마다 다음이 성립한다.

```
KL_k(β) = ½ ln(SNR_k / β)     (SNR_k > β일 때),    따라서    SNR_k = β₀ · exp(2 KL_k(β₀))
```

β₀ = 1 한 지점의 차원별 KL 스펙트럼만으로 모든 β의 곡선이 매개변수 없이 예측된다.

```
KL(β) = Σ_k [KL_k(β₀) − ½ ln(β/β₀)]₊ ,     n_active(β) = #{k : SNR_k > β},     β_c = max_k SNR_k
```

종점에 대해서는 두 가설을 구별할 수 있다.

- **전역 위상 가설:** 전역 병진 위상 2개가 끝까지 남고, β_c ≈ SNR_phase = 1.9×10⁴다(B3 측정).
- **구조 제한 가설:** 디코더가 병진 등변 합성곱이고 잠재 격자 셀 사이의 수용영역이 유한하면, 전역 위상을 한 곳에 담을 수 없고 셀(또는 수용영역 영역)마다 위상 사본이 필요하다. 사본 하나의 SNR은 대략 (I_shift/N_region)·p²/12이고, 6×6 셀이면 약 (3300/36)·5.8 ≈ 5×10²이다. 이 경우 β_c ~ 10²–10³이고, 붕괴 직전 기울기는 −(사본 수)이다.

차원별 스펙트럼 예측이 이 구별을 자동으로 해 준다. 최대 SNR_k가 어느 쪽 자릿수인지 보면 된다.

## 1. 작업 A — 역 water-filling 시험 (최우선)

### A1. 차원별 KL 스펙트럼과 예측 (재학습 없음)

대상은 B1/B2 이어서 학습 해(E2 독립, 시드 0, 1)다.

1. 각 β ∈ {0.01, 0.03, 0.1, 0.3, 1, 3}의 이어서 학습 해에서 잠재 차원별 KL(검증 표본 평균)을 1차원 배열로 저장한다.
2. `python stage2e_waterfill.py spec_b1.npy --beta0 1`로 β = 3 … 10⁴의 KL 예측과 활성 차원 수를 얻는다. 스크립트는 SNR 분위수도 출력하며, 이것을 보고에 먼저 적는다.
3. 차원별 법칙을 시험한다. `--check spec_b1.npy spec_b3.npy --beta0 1 --beta1 3`과, 같은 방식으로 (0.3, 1), (0.1, 0.3) 쌍에 대해 실행한다.

**기준.**
- 같은 차원에서 KL_k(β₁) = KL_k(β₀) − ½ ln(β₁/β₀)가 성립한다. 대응 차원들 사이의 상관 > 0.9, RMS 차이 < 0.15 nat.
- 꺼질 것으로 예측된 차원의 80% 이상이 실제로 꺼진다.

차원 축 정렬이 깨져 있으면(같은 차원 번호가 같은 모드가 아니면) 이 비교는 실패할 수 있다. 그 경우 사후 평균의 공분산을 주성분으로 회전한 뒤 각 성분의 정보량 ½ ln(Var(μ_k)/⟨σ_k²⟩ + 1)로 같은 시험을 반복하고, 두 방식을 모두 보고한다.

### A2. β 연속 상승을 10⁴까지

β = 3 해에서 이어서, β ∈ {10, 30, 100, 300, 10³, 3×10³, 10⁴}로 기하급수적으로 올린다. 각 단계는 수렴(손실 상대 변화 0.1%/10에폭) 또는 최대 150에폭까지 학습하고, 시드는 2개다. 각 β에서 총 KL, 차원별 KL 스펙트럼, 재구성 손실을 기록한다.

**예측.**
- 관측 KL(β)는 A1에서 β₀ = 1 스펙트럼으로 만든 예측 곡선을 따른다. 기준은 β ≤ 100에서 상대오차 25% 안이다. 이 값은 A2를 돌리기 전에 보고서에 먼저 적는다.
- 종점(마지막으로 KL > 0.5 nat인 β와 그 직전 기울기)은 위의 두 가설 중 하나와 맞아야 한다. 판정은 하지 않고 어느 쪽인지 보고한다.

### A3. 상위 모드의 정체 (재학습 없음)

β = 1 해에서 SNR_k 상위 20개 차원과 무작위 20개 차원 각각에 대해 디코더 응답 δh_k = ∂h/∂z_k를 계산한다(사후 평균 z 주변에서 유한차분). 이 응답을 다음 기저에 사영한 비율을 보고한다.

- 국소 병진 ∂_x h, ∂_y h
- 국소 호흡: 스커미온 중심 기준 반지름 방향 미분
- 나머지

**예측.** 상위 SNR 차원일수록 병진 비율이 크다. 판정하지 않고 보고한다.

## 2. 작업 B — K+M1 연속 해 읽기 (재학습 없음, 가벼움)

대상은 Stage 2d B1의 K+M1(ℓ = 8, ρ = 0.5) β = 1 종점 두 개(KL 270, 297)다. 보고할 것은 다음과 같다.

1. **J, D 편향.**
2. **장 프로필.** Stage 2d A1과 같은 방식으로 마스크 사이트와 비마스크 거리 구간별 h_z를 본다. 마스크 사이트의 장이 텍스처를 따르는지는 마스크 영역 h_z와 데이터 S_z의 위상 고정도 R(k)로 확인한다.
3. **골짜기 관계 확인.** 비마스크 먼 곳의 결손 δ = 2.4 − h_far을 계산하고, J, D 편향이 dJ/J = 4.7%·δ, dD/D = −13.3%·δ에 놓이는지 본다. L = 48 기울기는 `stage2e_valley.py` 전체 실행으로 다시 계산한다.

**예측.** 마스크 장이 텍스처를 따르면 경계에서 골짜기를 미는 힘이 줄어, 붕괴한 K+M1(Stage 2c, 같은 ℓ, ρ)보다 결손과 편향이 작다. 모든 점은 골짜기 직선 위에 놓인다(Stage 2d M1 점들과 같은 직선, 기울기 오차 20% 안).

## 3. 작업 C — E3 운영점 실효 Fisher (가벼움, 낮은 우선순위)

대상은 E3 PL s0, s1과 SM 교대 s0다(Stage 2d 수렴 해). 검증 표본마다 사용 채널의 사후 표본 z로 재구성 손실을 계산하고, 참 B를 디코더 장에 직접 넣은 손실과 비교한다.

```
I_eff / I_PL = { E[재구성(표본 z)] − E[재구성(B 참값)] } / { ½ · I_PL · E[(B̂ − B)²] }
```

여기서 B̂ = h_z/β이고, I_PL은 표본별 PL Fisher(`probes.pl_fisher_field`)다.

**예측.** PL 실행에서 비는 약 0.8(실효 SNR 14/17)이고, SM 교대 s0에서는 약 1.0이다. 비가 1에 가깝게 나오면 차이의 원인은 다른 곳에 있으므로, 원인 가설만 보고한다.

## 4. 공통 규칙

- 우선순위는 A1 → B → A2 → A3 → C다. A1과 B는 재학습이 없으므로 먼저 보고해도 된다.
- A2의 예측 곡선은 학습 전에 보고서에 적고, 그 뒤에 관측과 비교한다.
- 결과를 맞추려고 조정하지 않는다. 사후 조정은 처음 결과와 함께 적는다.
- 모든 표에 시드 수를 적는다.
- 예측이 틀리면 원인 가설과 구별 실험을 제안하되, 실험은 다음 의뢰를 기다린다.
- 코드 규약(부호, 매개변수 순서, DMI 방향)을 바꾸면 명시한다.

## 5. 제공 파일

`scripts/`에 넣는다.
